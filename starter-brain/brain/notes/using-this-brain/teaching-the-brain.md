# Teaching the brain

- **Tell it.** "Remember that the report is due March 3." It saves a note and says where.
- **Give it documents.** Drop files in `brain/inbox/` and say "process the inbox". Each document gets a summary in `brain/sources/`, and its facts go into notes that cite it.
- **Correct it.** "That's wrong, the deadline moved to March 10." It fixes the note, keeps a record of the old value, and adds a test question so the fix sticks.
- **Teach it a procedure.** "Learn to write my weekly update: …" It saves the steps as a new skill it can repeat.
