# Memory paths

The brain does not read everything for every question. It follows a path:

1. **Routing** (`brain/routing.md`): a short table of "when asked about X, start with these notes".
2. **Index and hubs**: the index lists every note by domain; each domain hub links its key notes.
3. **Links**: notes link to related notes with `[[note-name]]`, so one good note leads to the next.
4. **Search**: only when the path runs out.

When it has to search widely, it adds a row to the routing table, so the next similar question goes straight to the answer. The **Graph** view in the app draws these notes and links as a map.
