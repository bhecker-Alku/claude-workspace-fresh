# Start Claude Workspace

1. To start or open it, run `npm start` in this folder. It checks Node.js, installs on first run, starts the app in the background, checks the Claude sign-in and opens the browser at http://127.0.0.1:4317. Pass on what it printed in one or two plain lines, including anything it says is missing.
2. To stop it, run `npm run stop` (or tell the person to hold the ⏻ in the top bar for a second).
3. Do not edit any files.
